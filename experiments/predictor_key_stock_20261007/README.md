# Original ranked residual comparison

Frozen root queue and collector recipes require the owned artifacts in the
112-pin source packet and original absolute paths. Stock2078/2079 includes all
producer and ranked adapter work, private scratch allocation, seed transfers,
configuration, readback, reload and final completion. Verification is outside
the timed interval and covers every original output/input/descriptor/flag and
4,096 output guard bytes. Actual ELF and bitstream identities were preserved
before queue teardown. Full original source/predictor enumeration covers all
65,536 distinct signed-byte pairs.

The stock result is 1,339,430 versus 1,261,604 cycles. It is a section gain;
whole-model selection and timing require their own qualification. The large
GSIM attempt stopped before the final protocol marker and is retained as an
incomplete observation, not a qualified performance result.

The generic complete-key-fibre correction proof belongs to Merlin. Accumulator
DMA representability, activation/scale order, scratch layout, target commands
and actual execution capability belong to OOT. Production Spike and GSIM
disagree for negative-scale ReLU ordering. The admitted realization avoids
that ambiguous combination and applies ReLU in a separately checked product.
No target simulator implementation was changed to make this candidate pass.
