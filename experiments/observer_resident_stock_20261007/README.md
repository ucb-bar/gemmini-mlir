# Root stock observation recipes

These frozen experiment drivers submit and collect complete source-bound
capsules on `alveo_u250_firesim_gemmini_rocket_stock` using firesim-queue.
The queue owns setup, staging, simulation and teardown. Run from the OOT source
with its package importable and the pinned assets available. Each submission
requires a fresh adjacent output directory and the exact source packet; its
observer records actual staged ELF and stock bitstream identities before teardown.
Submission belongs to the root queue owner.

`submit_rne_zero_stock.py` / `collect_rne_zero_stock.py` bind stock2082's complete
M8 ABBA protocol, original45,056 bytes and source pins. The section improves
6.15651%. Historical full-cell source-driver drift remains explicitly unpromoted.

`submit_source_stride_pair_stock.py` / `collect_source_stride_pair_stock.py`
bind stock2083/2084's two complete original convolution ELFs, common addresses,
both stores, exact decoder and50,176 original outputs. The section improves
10.2899%; causal issue/cache attribution and whole performance remain separate.

`submit_rne_zero_whole_stock.py` binds the260-pin original Tiny2076 successor,
checks original Torch tolerances and all256,000 strict source output words,
then admits the exact ELF to stock2085. `collect_rne_zero_whole_stock.py` closes
the original complete output protocol and stock identities:378,946,263cycles,
1,450,080 fewer than2076. Whole cycles were unknown at submission.
The repeated inherited build marker is not an executable identity.

All paths and hashes are experiment provenance. Production compiler legality
and selection do not depend on those workload paths or observed output values.
