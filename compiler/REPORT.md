No new approximate kernel or numerical tolerance is declared.

Host regions use Merlin's tensor lowering, preparation, runtime and CPU numerical contracts. Unsupported accelerator arithmetic remains explicit in placement diagnostics; no CPU replacement is introduced for a required device contraction.

## Compiler changes

Optional frontier issue orders are exposed. Current order is retained: column-first differences are tiny and mixed on fresh validation, and K-frontier fusion gives identical complete cycles on both training cases.
