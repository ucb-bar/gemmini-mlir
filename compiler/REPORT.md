# General Gemmini compiler continuation

The compiler continues the supplied seed in `backend/` and the selected editable `compiler_library/`. Dense, convolution, pooling, elementwise, movement, source regions and their alternatives use the same terminal ISA encoder. Typed source axes, input pitches and offsets, initialization, observers, storage ownership and completion edges survive into the shared schedule checks. Merlin supplies host tensor preparation, runtime, floating arithmetic and CPU lowering.

Implemented extensions include exact ranked readout, readonly pitched movement/residual/bias inputs, a compiler dependency bootstrap, adaptive segmented-K prefetch, complete-RHS retention inside the retained fallback, source-bound readonly pitched inputs, standalone per-column i32 readout, exact accumulator epochs, minimum-halo convolution/readout/pool composition, guarded interior convolution transfers, multi-output convolution groups, and ranked standalone readout through the whole-program ABI. Optional shared-RHS capacity panels retain original per-member M and physical N pitches. Unsupported proofs retain a valid accelerator schedule or explicitly decline; they do not silently move supported contractions to the CPU. Original direct-input returns remain outside the selected one-shot output-owner ABI.

Actual placement reports preserve original source indices and compiled device-group memberships. Their static tensor extents are not measured traffic. Independent eligibility, measured host time, queue occupancy and processing-element occupancy remain UNKNOWN where the selected tools do not establish them.
