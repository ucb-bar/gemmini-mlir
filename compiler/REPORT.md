# General Gemmini compiler — continuation report

The compiler in `submission/` lowers the selected public interface and tensor sources through one shared target encoder. Public inventory:152 cases (101 original correctness,8 calibration,40 scalability,3 connected programs); launch core109. Fourteen private inputs remain sealed.

## Implementation

- General signed contraction lowering handles contiguous/batched/broadcast layouts, projected input/output permutations, live i32 initializers and multiple reduction axes in source order. Unsupported signed contraction semantics refuse before host tensor lowering.
- Dense and convolution source axes, addresses, storage effects and completion dependencies survive shared scheduling transformations. The terminal encoder consumes the actual transformed artifact; original and alternatives use the same encoding path.
- Dense default retains complete-K invariant RHS panels across multiple full M groups when source, capacity and completion proofs admit it, combines ready readout with wide contiguous transfers, and preserves the incumbent outside this structural region. `dense_rhs_reuse=off/ready/wide` exposes real alternatives.
- Convolution automatic phased-RHS planning jointly bounds phase width and multirow input storage. Full-fit RHS incumbents remain unchanged. Singleton mixed-scale output columns use a counted loop with the original scale bits loaded into hardware store configuration; tensor arithmetic stays on Gemmini.
- Source-proven identity-mapped scalar quantization chains can read directly to i8 with exact scale/ReLU. Full-i32 ordered-f32 proofs, source/path identity and observer checks govern admission. Runtime/per-column source chains retain their original numerical boundary when proof is unavailable.
- Host tensor preparation, source operations and CPU arithmetic reuse Merlin. Native binary32 sine/cosine, roundeven and quantization preserve source semantics. Source-composition requests preserve incumbent host fusion while alternative preparation/storage choices are evaluated separately.
