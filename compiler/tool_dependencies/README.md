This is the unmodified public z3-solver 4.16.0.0 host verification dependency.

The archive contains its Python modules, one original libz3.so, MIT license and
provenance. It excludes headers, bytecode caches and the duplicate shared library.
The manifest records packed bytes, total unpacked bytes and every raw file hash.
The compiler loads ordinary installed z3 first, otherwise extracts this package
into a process-private temporary directory and verifies all bytes before loading.
This archive is retained compiler input; its full size must count in source
resource accounting. Extraction consumes the documented raw bytes at runtime.
