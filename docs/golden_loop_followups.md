CCA should expose preparation/representation boundaries and observation costs
through source-resolved regions and resource terms. Useful new terms include
prepared bytes, packing operations, certification operations, ambiguous-source
continuations and owner-lifetime boundaries. Each term needs an emitted or
executed derivation; it cannot be populated from an intended schedule alone.

The numerical/ownership/preparation contracts and resource-independent planning
belong in Merlin. Model capture, QDQ/source-axis identity and frontend
normalization belong in model2MLIR. Target instruction semantics, controller
geometry, physical resources, schedule/layout plans and target consumption
belong in the OOT dialect. Compiler rules use source semantics and target
capabilities; model names and reference outputs authenticate experiments only.

## Specific OOT requirement caught by this campaign

Readout-plan cloning dropped a newly requested tile-order option while metadata
claimed it was applied. The rejected source build is preserved, and the narrow
choose-to-emitted-object regression now checks the actual result. Introduce an
immutable typed target schedule record whose fields survive readout selection
through a checked replacement operation. Actual command/object closure remains
necessary. This is a compiler-plan preservation rule across workload families.
