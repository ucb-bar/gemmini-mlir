# Automatic-loop mechanisms: implementation boundaries

This record distinguishes reusable code from a completed experiment. The
handwritten investigation has **not** demonstrated fresh Phase1/2 convergence
matching the three whole-model references, or a matched 20x elapsed-time gain.
Investigation collaborators are not independent experimental authors.

The existing global analytical installation factory is not wired into independent
component analytical feedback; that profile accepts an explicit custom callback.
A reusable calibrated component adapter still needs integration. Certified GSIM
sweep fan-out and Phase1 asynchronous job/lease controls already exist, while the
unified supervised independent CPU campaign remains incomplete.

The size extension implements a test-generation rule. It does not add a backend
residency policy, observe physical transfers, infer cache facts or certify a
performance winner. Component objective admission also does not grant timing.

Provenance-preserving QKV CSE remains a structural prototype. Scoped floating
epochs remain paused/unqualified. Automatic equivalence classes for failed
policies, a universally complete exclusive cost ledger and autonomous profitable
representation/packing selection are still proposed work.

The generic CCA, calibration, portfolio and edit foundations predate several of
our delivery topics. Incoming upstream coherent-memory, schedule-proxy and
performance-basis changes are separate upstream contributions. Do not attribute
all available infrastructure to this session's new commits.

profitability and transfer obligations. The [CPU search policy](fast_search_policy.md)
states how existing tools could shorten the loop and where calibration is missing.
Neither investigator document belongs in an independent author view. Generic
Merlin improvements require explicit admission; handwritten target implementations,
captured models, outputs and historical performance labels remain excluded.
