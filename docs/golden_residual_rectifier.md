# Exact finite residual rectifiers

This is an optional compiler experiment. Existing source routing and the exact
residual implementation remain unchanged. The original whole-model accuracy
gate is all 1,000 binary32 words exact, with `atol=rtol=0`.

## Source proof and ownership

Merlin's `quantized_affine_rectifier` derives a correction circuit from the
complete 65,536 signed-byte input pairs. It re-derives the ordered binary32
source and predictor tables, every mismatch, all intermediate integer ranges,
and the final observation. A runtime distribution never grants eligibility.

The generic certificate supports multiple singleton corrections. The current
OOT provider accepts an empty relation or one singleton. It explicitly refuses
multiple relations, incomplete row/column tiles, missing capabilities, changed
certificates, resource overlap, and seeds outside the signed-byte real-D input
range. A mathematical certificate does not establish floating environment,
target capability, storage ownership or profitability.

The target ABI is four pointers: immutable dense i8 A/B, fresh private i8 C,
and immutable coefficient/seed tables. C must be disjoint from all inputs,
remain unpublished during the predictor store/reload, and become available only
after the final completion fence. Normal-model routing has not been enabled.

## Device realization

The accepted capability experiment uses ordinary WS primitives with SPAD A/D
reads, SPAD writes, signed i32 accumulation, and narrow ACC DMA stores. It uses
neither ACC execute reads nor STORE_SPAD. The original first source certificate
has one mismatch; its source-derived axis-offset circuit requires five
predictor products, eight rectifier/indicator products, and one final product.
This is 14 products per tile versus the unchanged control's 39.

The prediction is stored to private C and reloaded into SPAD. All table loads,
seed loads, stores, reloads, CPU command issue and completion fences are included
in the measured complete kernel/ranked-adapter scope. Nominal array work is not
a hardware cycle floor.

## Capability evidence and refusals

The stock source configuration enables ACC execute reads, but the initial
independent ACC-read probe failed with the production Spike extension and
stalled on the pinned GSIM. A phase-split probe isolated the stall to the first
ACC-read execution. These failures remain in `out/rectifier_capability_v1`,
`out/rectifier_capability_v2` and `out/rectifier_phase_v1`.

An isolated copied functional extension supports narrow ACC execute reads and
passes the tiny probe; unchanged current2039 stdout/histogram bytes also close.
This is diagnostic functional evidence. The production engine is untouched,
and the failed GSIM path has no hardware capability grant.

The fallback SPAD real-D probe passes production strict RV64GC Spike and GSIM,
including both signs, clipping/ReLU, full ACC readback and output guards.
See `out/rectifier_spad_capability_v2`. Independent nonsquare M48/N128 source
outputs and guards pass in `out/rectifier_independent_n128_v2`. Sixteen target
resource/refusal tests and 39 shared numeric tests pass.

## Actual emitted work and model scope

The original 802,816-element ranked pair uses the actual current kernel and
adapter objects. The control kernel is regenerated byte-for-byte identically.
Both selector ELFs use common addresses, identical warmups and outside-ROI
checks; their sole byte difference is a data selector. Both production strict
Spike arms pass all outputs, input immutability, descriptor preservation,
guards and unchanged floating flags.

The existing observational engine reproduces the production console and PC
histogram exactly. Per-invocation features come from actual ELF function entry
counts and executed operands:

| Feature | Current39 | Rectifier14 |
|---|---:|---:|
| Nominal padded compute rows | 1,956,864 | 702,464 |
| Real stationary B preloads | 3,136 | 10,976 |
| Requested load bytes | 1,606,400 | 2,414,848 |
| Requested store bytes | 802,816 | 1,605,632 |
| Retired kernel instructions | 378,478 | 218,867 |
| Executed fences | 2 | 7,843 |
| Touched instruction bytes | 1,954 | 1,342 |

Requested payload is not physical DRAM traffic. CPU load/store counts do not
establish stack addresses without separate disassembly/operand closure.
The frozen2038 row/real-B law gives conditional arithmetic of 2.274M versus
0.915M, but its ordinary resident-array domain does not cover real-D/SPAD writes,
rectifier dependency chains, extra transfers, seeds or these fences. Approved
cycle prediction and whole-model gain therefore remain UNKNOWN.

## Reproduction and next decision

`tests/reclose_nominal_work_alignment.py` independently re-closes all 54 pinned
role/geometry pairs, 16 residual source coefficients and both 8,192-row integer
mean counts. The historical receipt remains immutable in the host-eight tree.

`tests/affine_rectifier_ranked_probe.py` binds source/capture/control objects and
times the entire ranked ABI. `tests/affine_rectifier_request_census.py` joins
qualified executed requests with the existing shared feature provider. Complete
original-input timing decides whether normal-source implementation selection is
justified. No queue submission or production promotion is authorized by these
notes. Internal fence coalescing is a separate future candidate requiring exact
pinned reservation/execute hazard and storage-lifetime proof.
