# Complete source-table refinement capsule

The fixed explicit 13-bit/16-bit hierarchy has a source-wide certificate for the
same rounded expression and closed integer observer as the current 2085 helper.
The generic implementation is local Merlin topic `47ab40250`; target mode guards,
existing RNE legalization, object linkage and this source-bound experiment belong
to OOT. It is held for complete-cost measurement, with no default or whole-model
promotion.

All 991,232 original integer observations across 22 source contexts are unchanged.
The coarse 64 KiB table certifies 892,490 elements; 98,742 request the existing
512 KiB table. Original source replay remains 13,375 calls. Total logical table
requests grow 9.96%, finishing multiplies grow 8.15%, and endpoint quantizer calls
grow 16.19%. Fine-table distinct logical 64-byte regions summed per context fall
from 9,436 to 3,942, alongside 1,482 coarse-table regions. These are table-only
logical requests, not measured cache misses or physical DDR traffic.

The complete first-M8 strict target passes all 45,056 original integer bytes,
five rounding modes, seven sticky input contexts, dirty guards and immutable
inputs. Flags are explicitly unobserved; no flag-parity claim is made. Unsupported
modes retain the complete original source helper. Both scale scans, source casts
and rounded products, table traffic, certificates, refinements, original cold
source continuation, frames, dispatch and output stores are inside each ROI.

The named-storage successor changes only the validation harness. Every ABBA
window records the same input, expected output, guard arena, output, fine-table
and coarse-table addresses. Table bytes are hashed outside each ROI. The same
helper and table objects are retained; a fresh complete relink reproduces its
ELF exactly. There is no dynamic private scratch arena; stack frames differ and
remain unpriced. Existing unused legacy table owners remain in both arms.

Control executes 1,726,425 retired instructions; hierarchy executes 1,764,710
(+2.217%). Functional Spike counter values are not hardware cycles. Hardware
cost and whole-model cost remain unknown. The paired ELF's initial source gate
warms both helper/table paths, so it does not measure an independent cold-cache
regime. No whole prediction is derived from this one fixture.

The original census, strict capsule and first timing ELF remain immutable.
`receipt.json` binds their source, proof, tool, object, log, data and final link
identities, final C re-emission, 65 focused tests, parser refusal cases and the
fresh named-storage successor. Initial tool, C-name and census-rank failures are
retained separately. Per-agent token accounting is unavailable; the parent
captures shared campaign checkpoints.
