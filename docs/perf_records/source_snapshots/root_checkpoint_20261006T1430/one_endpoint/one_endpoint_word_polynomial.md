# One endpoint polynomial word enclosure

The optional `one_endpoint_word_enclosure` source-frontier choice requires
`word_interval_enclosure`. It retains original source polynomial arithmetic,
certification and replay. Default emitted source is unchanged.

A borrowed immutable prepared polynomial proves monotonic real `E(s)` and a
uniform source rounding budget. Within one floor segment, a prepared power of
two bounds its encoded derivative. Ordered binary32 word distance and maximum
ULP bound the scaled input distance, including subnormals and signed zero.
One original source evaluation plus this distance and the two-error budget
enclose every interior source word. A separately proved global source upper
word caps the enclosure. Floor crossings and unsupported preparation use the
existing enclosure. Prepared softmax verifies that this cap fits its admitted
positive prefix domain; otherwise it retains checked source execution.

Preparation requires the existing stable RNE, nontrapping, unobserved exception
contract. The original live source operands, private ownership and complete
consumer proofs remain mandatory. Wider intervals can cause more source replay;
section timing alone does not establish complete-group profitability.
