## Factories and parallel execution are different workflows

The existing `phase2_analytical_provider.build_fast_evaluator_installation` is the
legacy global four-model factory. It requires its selected quality observer and
calibration and constructs a global experiment; it is not the component analytical
callback. Reuse generic calibration/interval machinery without exposing global
model inputs to the independent component profile.

Phase1 async sim jobs and certified GSIM sweep prefetch/fan-out are implemented.
The whole-portfolio analyzer also has a memory-bounded thread pool, but that is
another workflow. A unified supervised independent native/Spike/analytical/RTL
campaign, cancellation and qualified fresh launch still need integration.

Final-gate arithmetic cannot authenticate caller-supplied hardware hashes,
elapsed times or booleans. Trusted build/execution/evidence joins must establish
them. A success in a synthetic process test is not an automatic campaign result.

## Where the agent should modify the compiler

With explicit frozen authority, generic host fusion/scheduling, packing,
requantization, allocation, dispatch and runtime composition are Merlin edit
surfaces. Target tiling, residency, banking, command schedules, dialect lowering,
ISA and ABI are OOT surfaces. Import fidelity belongs in model2MLIR.

Representation policies require current source/user/effect proofs, explicit
numerical permission and original fallback. Fixed graders, budgets, reference
outputs, hardware facts and permissions are protected. Using an admitted library
API does not make the entire library editable.

The [implementation inventory](automatic_loop_implementation_status.md),
[capsule matrix](capsule_optimization_coverage.md) and
[CPU search policy](fast_search_policy.md) connect these interfaces to required
tests, feedback and outstanding work. Independent small composed networks remain
a generation requirement, not an implemented general composer. Roofline bounds
remain useful alongside dependencies, preparation, calls/frames, cache, replay and
publication prices; unresolved comparisons remain unresolved.
