# Exact residual diagonal feasibility

The experiment evaluates `clip_i8_relu(round_even(f32((a*p+b*q)*s)))`, with exact i32 accumulation, positive finite f32 readout scale `s`, and integer coefficients `p,q` in0..127. Every captured scalar residual is compared over all65,536 signed-i8 operand pairs with its original separately rounded f32 dequantizations, addition, ReLU and reciprocal multiplication. No graph or numerical policy is changed.

**None of the16 residuals is feasible in this scheme.** For every residual, all16,384 coefficient pairs have contradictory necessary intervals for the readout scale. Intervals account for f32 multiplication rounding by moving each half-integer output transition to the midpoint of its adjacent f32 values. Binary64 division bounds are widened outward by one ulp before intersection, so rejection is conservative. A surviving f32 candidate would be checked independently against all pairs. Three positive controls, including coefficients127/113 at scale1/256, recover exact candidates.

The report pins the source proof report and search source hashes and records a concrete contradictory interval for the closest bounded rational coefficient ratio. `mlir_oot/golden_resadd_diagonal_search.py` reproduces the search. Its result records one exact representative scale per feasible coefficient pair, rather than enumerating every equivalent scale. Negative coefficients cannot help these captures: setting the other operand to zero and the selected operand positive produces a positive source output but a nonpositive accumulator.

This excludes only the stated bounded two-diagonal scheme. It does not exclude wider decomposed coefficients, other integer algorithms, exact CPU lookup tables, or an explicitly approved numerical tolerance experiment. A65,536-byte table per scalar qparam tuple can exactly encode the entire source residual map without runtime floating arithmetic;16 unique tuples require1MiB. Such a path needs source/hash binding, table-byte identity and complete-domain verification before use.
